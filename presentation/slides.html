Slide 2 of 5 Design Decisions

Distinctive Architecture & The 5 Primary Manager Questions

SpendNest Signal Desk answers the exact operational questions a revenue manager asks every day.

The 5 Core Workflow Questions

  • 1. What happened on 21 August 2026? Executive memo synthesizing 44 interactions (30 calls, 14 meetings) across 4 active SDRs and 7 organizers.
  • 2. Which conversations need attention? Front-and-center Attention Queue prioritizing unconfirmed records, bugs, and coaching flags.
  • 3. What evidence supports conclusions? Primary evidence banners anchoring conclusions directly to 1-based turn numbers or quotes.
  • 4. What action next? Prescribed next steps with explicit owners (Engineering triage, 1-on-1 roleplay, pricing sheets).
  • 5. What has changed since last import? Recent Changes Audit Log tracking Revision 2 arrival, late transcript unlocks, and preserved overrides.

Deliberately Excluded Features (Focus & Scope)

  • No Speculative Deal Value / Win Probabilities: No CRM opportunity table exists in raw data. Inventing "$500k Pipeline" figures violates DATA_CONTRACT.md.
  • No Unwarranted Cross-Rep Performance Rankings: Activity represents a deliberately selected sample of 44 records across different roles (SDRs vs implementation specialists), not a complete day.
  • No Runtime Cloud LLM API Dependency: Avoids paid account requirements, token leakage, and non-deterministic grading behavior during evaluation.

Slide 5 of 5 Trade-offs & Future

Trade-offs, One Rejected Decision & Future Roadmap

Reflections on technical trade-offs, AI utilization, and future platform scale.

The Deliberately Rejected Decision

Runtime Cloud LLM API Integration

Alternative Considered: Calling external OpenAI / Claude API at runtime to dynamically summarize conversations and score deals.

Why Rejected: Violates assignment self-containment, risks credential leakage, introduces latency, and produces non-deterministic routing that fails replay idempotency.

Trade-off Accepted: Deterministic knowledge rules with pre-generated structured analysis and human manual review capabilities.
